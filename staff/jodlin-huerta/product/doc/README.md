## Intro

An for pet owners register their pets and their medical information, to have control on the their history.

## functional

### Use cases

User

- register
- login
- update credentials (username, password)
- update profile (name, email, phone, city, role, licensing number)

Owner (User)

- add pet
- remove pet
- modify pet
- list pets
- add comment log from pet
- remove comment log from pet
- modify comment log from pet
- list logs from pet
- filter veterinary (by city)
- assign veterinary for pet
- unassing veterinary for pet

Veyterinary (User)

- list assigned pets
- add, remove, modify action log for pet
- list logs from pet
